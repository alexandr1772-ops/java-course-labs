# Лабораторная работа 2. Классы и инкапсуляция

Направление: инженерия систем искусственного интеллекта.

## Инварианты

**BankAccount**
- Начальный баланс не может быть отрицательным.
- Сумма пополнения и снятия всегда положительная.
- Нельзя снять больше денег, чем есть на счёте, или переполнить `int` при пополнении.
- Баланс меняется только через `deposit` и `withdraw`.

**DataSample**
- `id` и `label` не равны `null` и не состоят только из пробелов.
- `status` не равен `null`. Изменение статуса — только через `changeStatus`.
- Массив `features` не равен `null`, не пуст и содержит конечные числа.
- Массив копируется при создании объекта и при вызове `getFeatures`.
- Наблюдение готово, если его статус `READY`.
- Среднее значение вычисляется методом `averageFeatures`.
